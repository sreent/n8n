# The map of the fork: each path that the fork adds to upstream n8n, in an area with a layer and a
# document. FORK-MAP.md describes the layers and the areas. scripts/fork-map.sh reads this file,
# and scripts/container-ci.sh checks it.
#
# An area line starts an area: `area <name> <layer> <document>`. The document describes the area.
# The lines after an area line are the paths of the area, one for each line, relative to the
# repository root. A path that ends with / names a folder and everything in it. Lines that start
# with # are comments.
#
# The layers:
#   rebuilt     the fork's own versions of the enterprise features of n8n
#   switch      the fork switch, which turns on the licence features
#   fork        the features of the fork
#   core        fork files in the community core of n8n, which are not part of a feature
#   operations  deploy/, scripts/, vendor/ and the documents of the fork
#
# Each path holds fork files only: a file that is not in the upstream commit of
# scripts/sync-upstream.base, or a folder of such files. Each file that the fork adds is in a path.
